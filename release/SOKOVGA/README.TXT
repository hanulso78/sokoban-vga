소코반 (SOKO-BAN) - VGA 256색 개선판

  1988년 Spectrum HoloByte 판 소코반(SKB.EXE)을 역어셈블해서 C 로 옮긴 뒤,
  화면을 VGA 256색으로 다시 칠한 판입니다.
  게임 규칙, 단계, 글(영어) 은 원판 그대로입니다.

    - VGA 모드 13h, 모든 화면을 256색으로 다시 칠함
      (첫 화면, 로비, 선수 화면, 엘리베이터, 판, 일시정지, 편집기)
    - 판: 벽돌 벽, 돌 바닥, 나무 통, 안전모를 쓴 일꾼
    - 엘리베이터 문과 로비에서 걷는 사람의 움직임을 부드럽게
    - 애드립 음악 (애드립/사운드블래스터가 있을 때)
      첫 화면 / 판 / 단계 성공 (SOUND.DAT 에 들어 있습니다)
    - 시작할 때 묻는 두 질문(시스템 종류, 입력 장치)은 자동으로 답합니다
      (CGA, 키보드).  조이스틱을 쓰려면  SOKOVGA /J  로 실행합니다.

하는 법
  첫 화면에서 Enter -> 로비에서 PLAY 엘리베이터 앞에서 Enter
  -> 선수 이름을 치고 Enter, 빈 칸에서 한 번 더 Enter (혼자 하기)
  -> 엘리베이터에서 층(단계) 번호를 누르고 A (Accept)
     C = 지우기, L = 로비로
  로비의 EDIT 엘리베이터 = 단계 편집기 (51~99 단계를 만듭니다)
  EXIT 문 = 끝내기

판에서 쓰는 키
  화살표   움직이기 / 상자 밀기
  U        한 수 되돌리기          F1   이 단계 처음부터
  P        일시정지 (기록 보기, 게임 저장)
  F2       소리 켜기/끄기          F3   이 단계 기록 지우기
  Esc      판에서 나가기

실행
  DOSBox 나 도스에서 이 폴더로 가서  SOKOVGA  라고 칩니다.

이 폴더의 파일
  SOKOVGA.EXE    게임
  CWSDPMI.EXE    도스에서 32비트로 돌리기 위한 DPMI 서버 (같이 있어야 합니다)
  SKBVGA.DAT     256색 그림 (화면, 스프라이트, 타일, 글꼴의 색)
  SOUND.DAT      애드립(OPL2) 곡 셋 (첫 화면 / 판 / 단계 성공)
  나머지         원판 자료 파일 (그림, 단계 TABxxxx, 편집 단계 EDTxxxx,
                 기록 MOVE/PUSH/TIME/SCORE/NAMES)

  게임이 저장하는 파일: 최고 기록은 MOVE, PUSH, TIME, SCORE, NAMES 에,
  일시정지 화면에서 저장한 게임은 SINGLE, 토너먼트는 TOUR 와 PL1~PL4 에.
  자료 파일과 기록은 원본 배포판(1987~1990) 그대로입니다.
